# Решения задач по Python

Здесь собраны самостоятельные решения практических заданий по Python.

## Обработка текста

`task13_1.py` выполняет лемматизацию русского текста, удаляет стоп-слова и сохраняет результат в `result.txt`. Для запуска положите свой исходный текст в `text.txt` и выполните:

```bash
python task13_1.py
```

Нужны пакеты `nltk` и `pymystem3`. При первом запуске скрипт загрузит список стоп-слов NLTK. Библиотека `pymystem3` при необходимости загрузит программу MyStem.

## Бот с прогнозом погоды

`weather_bot.py` показывает текущую погоду в Москве, Санкт-Петербурге и Казани. Для запуска установите зависимости и задайте собственные ключи через переменные окружения `TELEGRAM_BOT_TOKEN` и `WEATHER_API_KEY`:

```bash
pip install requests pyTelegramBotAPI
python weather_bot.py
```

Ключи в репозитории не хранятся.
